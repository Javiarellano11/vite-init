# Trabajando con VITE

## Creo el esqueleto para no empezar de cero

```sh
npm create vite@latest ./
```

## Instalo las dependencias

```sh
npm install
```
# Arranco servidor de desarrollo

```sh
npm run dev
```

## Detengo servidor de desarrollo

Ctrl + C
